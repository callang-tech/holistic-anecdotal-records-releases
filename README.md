# Holistic Anecdotal Records

Official Windows releases of **Holistic Anecdotal Records (HAR)** — a
Holistic Educational Anecdotal Record & Tracking System.

This repository is used for distribution of official Windows releases.

## Download

Installers are available from the **Releases** section of this repository.

## Platform

- Windows 10/11
- 64-bit

## Data Security

HAR supports encrypted Google Sheets synchronization using AES-256-GCM,
Windows Credential Manager key storage, and password-protected recovery-key
export/import.

Users who enable encrypted synchronization should export a recovery key and
store the recovery file and its password securely and separately.
